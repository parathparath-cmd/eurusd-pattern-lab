# EURUSD Pattern Lab

An open-source Python research framework for discovering and evaluating recurring patterns in the EURUSD forex market.

## Objectives

- Explore historical EURUSD price patterns.
- Compare candidate strategies against simple baseline models.
- Evaluate performance using walk-forward testing.
- Measure expectancy, profit factor, trade count and maximum drawdown.
- Encourage reproducible, statistically rigorous trading research.

## Research Methodology

The project is intended to use chronological training and testing, realistic transaction costs, and out-of-sample evaluation to reduce look-ahead bias and overfitting.

## Project Status

Early-stage research project. Results and implementation details will be documented as experiments become reproducible.

## Technology

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
